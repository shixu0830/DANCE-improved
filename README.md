# DANCE-improved

R + Rcpp implementation of a data-driven, automated algorithm for discovering *disconnected negative controls* that can serve as surrogates for unmeasured confounders.

This repository provides an improved version of the original DANCE algorithm by incorporating Rcpp for faster computation and adding several additional screening steps:  
https://github.com/imjaewon07/DANCE  

The method is based on the approach developed in:  
https://www.jmlr.org/papers/v25/22-1062.html
